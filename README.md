# 扫雷游戏 Web Demo

这是一个基于原生 HTML、CSS 和 JavaScript 实现的扫雷游戏前端 Demo。项目以“学习式实现”为主，完整展示了扫雷游戏中的棋盘生成、随机布雷、数字提示、递归展开、右键标记、计时器和难度切换等核心逻辑。

## 项目概述

该项目是一个典型的前端小游戏案例，主要用于帮助学习以下内容：

- DOM 创建与事件绑定
- 二维数组和棋盘数据结构设计
- 随机布雷和邻雷计数算法
- 递归遍历空白区域
- CSS 布局和样式设计
- 前端状态驱动的交互逻辑

它不仅能运行，还能作为理解“原生 JavaScript + DOM + CSS”组合开发小游戏的良好练习示例。

## 功能特点

- 支持三种难度：初级、中级、高级
- 随机生成雷区并计算每个格子的邻雷数量
- 左键打开格子
- 右键设置旗标、问号和取消标记
- 点击空白区域时自动展开相邻空白区域
- 显示剩余雷数和计时器
- 提供重置按钮和重新开始按钮
- 失败后弹出遮罩层并中断计时

## 游戏规则

1. 左键点击格子时打开该格。
2. 如果点击到雷，游戏结束。
3. 如果点击到数字，显示当前格子周围的雷数。
4. 如果点击到空白格，则递归展开附近的空白格和数字格。
5. 右键点击可标记旗子，用于标记疑似雷区。
6. 通过清除全部安全区域并避免踩雷即可胜利。

## 技术实现说明

### 1. 棋盘数据结构

项目使用二维数组来保存每个格子的状态，例如：

- `value`：格子值，`-1` 表示雷，其他数字表示周围雷数
- `status`：当前标记状态，`0` 表示未标记，`1` 表示旗子，`2` 表示问号
- `open`：是否已被翻开

### 2. 布雷逻辑

在 `static/index.js` 中，随机遍历棋盘位置，放置指定数量的雷，并保证同一位置不会重复布雷。

### 3. 邻雷计算

通过检查目标格子周围 8 个方向的位置，累计雷的数量，再赋值给当前位置。

### 4. 递归展开

当点击到 `value === 0` 的空白格时，程序会递归遍历周围单元格，并逐步揭开连续空白区域。

### 5. 难度切换

项目中定义不同的棋盘边长和雷数：

- 初级：9 × 9，10 个雷
- 中级：16 × 16，40 个雷
- 高级：25 × 25，99 个雷

对应逻辑在页面中以按钮切换形式实现。

## 运行方式

### 方式一：直接打开页面

在项目根目录中，直接打开以下文件即可：

```text

```

### 方式二：本地服务器运行

推荐使用本地静态服务器，以避免浏览器跨域或路径访问问题：

```bash
cd d:\web\25-6-30__扫雷
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000/static/index.html
```
